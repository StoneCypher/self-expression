    Function renderTree

    • renderTree(
          root: string,
          children: Readonly<Record<string, readonly string[]>>,
          options?: TreeRenderOptions,
      ): string

      Renders a strict hierarchy — a decision tree, a module tree with annotations — as a connector tree (├─/└─/│), the simpler tidy layout the spec reserves for input that is genuinely a tree. Non-tree input is refused by naming the first node that appears under two parents (or in a cycle), so the caller knows to use renderDigraph instead.

      Parameters

      • root: string

        the root node's id

      • children: Readonly<Record<string, readonly string[]>>

        each node's ordered children, by parent id; ids absent from the map are leaves, and every key must be reachable from root

      • Optionaloptions: TreeRenderOptions

      Returns string

      Example

      renderTree('plugin', { plugin: ['skills', 'commands'], commands: ['claude', 'gemini'] })
        // => '┌────────────────┐\n' +
        //    '│ plugin         │\n' +
        //    '│ ├─ skills      │\n' +
        //    '│ └─ commands    │\n' +
        //    '│    ├─ claude   │\n' +
        //    '│    └─ gemini   │\n' +
        //    '└────────────────┘'

      Throws

      If a node repeats (shared child or cycle — the error names it), a children key is unreachable from root, the tree exceeds the node threshold, or a line exceeds the width budget; refusals name the fallbacks.
