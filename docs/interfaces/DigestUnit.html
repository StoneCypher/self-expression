    Interface DigestUnit

    One unit of a compressed artifact, reduced to exactly what the digest needs: the marker glyph it renders with, and — when the glyph alone can't carry it — which bucket it counts toward.

    bucket names one of the profile's bucket ids and wins outright over the marker's own classification when it does; an id the profile does not define is ignored and the unit classifies by marker as usual. Profiles that classify by something other than the marker (the diff profile's change kinds) rely on it entirely.

    plus/minus feed the +N −M tail of a plusMinus profile (lines added and removed by this unit, for the diff profile) and are ignored everywhere else.
