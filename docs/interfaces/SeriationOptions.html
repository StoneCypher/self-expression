    OptionalmaxPasses

    maxPasses?: number

    Barycentre passes per sweep, default DEFAULT_SERIATION_PASSES. A pass is one row ordering plus one column ordering; sweeping stops early when a pass moves nothing.

    • Defined in diagrams/matrix.ts:113

    OptionalmaxRounds

    maxRounds?: number

    Sweep-then-hill-climb rounds, default DEFAULT_SERIATION_ROUNDS. A round is kept only when it lowers the recomputed objective, so rounds stop at a fixed point rather than at this cap — which is what makes seriation idempotent.

    OptionalpinRows

    pinRows?: boolean

    Freeze the row axis in the caller's order (default false). Set this whenever the rows already carry an order a reader understands — releases, weeks, severity levels — since a better objective score is not worth an unreadable axis.
